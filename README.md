# Nausicaä

Site educativo onde você aprende sobre **fatos históricos**, assiste a **vídeos informativos**, conhece **obras** que ajudam no aprendizado e testa o que aprendeu em **quizzes**.

## Sobre o projeto

O Nausicaä reúne em um só lugar conteúdo sobre guerras históricas (causas e consequências) e obras que refletem sobre a paz. Depois de estudar, o usuário responde a um quiz e vê sua pontuação. Um painel administrativo permite cadastrar, editar e excluir o conteúdo do site.

Este é o Trabalho de Conclusão de Curso (TCC) do Curso Técnico em Desenvolvimento de Sistemas da **PROZ Educação**, turma 251BTTDS, com orientação do professor **Luciano Rocha**.

## Funcionalidades

- Consultar guerras, suas causas e consequências
- Assistir a vídeos relacionados
- Consultar obras sobre a paz
- Responder quizzes e ver o resultado
- Painel administrativo para gerenciar o conteúdo

## Tecnologias

- **Front-end:** HTML, CSS e JavaScript
- **Back-end:** PHP
- **Banco de dados:** MySQL
- **Versionamento:** Git e GitHub
