---------. Requisitos funcionais revisados .---------

- RF01 — Consulta de guerras: O sistema deve permitir que o usuário consulte informações sobre guerras históricas, suas causas e consequências.
- RF02 — Exibição de vídeos: O sistema deve permitir que o usuário assista a vídeos relacionados às guerras, como conteúdo complementar e opcional.
- RF03 — Consulta de obras: O sistema deve permitir que o usuário consulte obras que apresentam reflexões e propostas para promover a paz.
- RF04 — Questionários: O sistema deve permitir que o usuário responda a perguntas sobre os conteúdos apresentados.
- RF05 — Resultado dos questionários: O sistema deve apresentar a pontuação obtida pelo usuário após responder às perguntas.
- RF06 — Navegação: O sistema deve permitir que o usuário navegue entre as páginas e funcionalidades disponíveis.
- RF07 — Gerenciamento de conteúdo: O sistema deve permitir que um administrador cadastre, consulte, altere e exclua informações sobre guerras, obras, vídeos e questionários.



---------. Requisitos não funcionais .---------

- RNF01 — Responsividade: O site deve funcionar em computadores, tablets e celulares.
- RNF02 — Usabilidade: A interface deve ser organizada e de fácil utilização.
- RNF03 — Segurança: O sistema deve validar os dados recebidos e proteger as credenciais do banco de dados.
- RNF04 — Desempenho: O sistema deve apresentar carregamento adequado das páginas e informações.
- RNF05 — Compatibilidade: O sistema deve funcionar nos principais navegadores modernos.
- RNF06 — Integridade: O banco de dados deve manter os relacionamentos e a consistência das informações.
